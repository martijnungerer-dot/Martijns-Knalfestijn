## Claude Code op het web

Deze repository wordt ook met Codex ontwikkeld. Gebruik dezelfde productafspraken en architectuur. Lees `STATUS.md` om de eerstvolgende taak te bepalen. Werk op een afgebakende eigen branch en werk de status bij met daadwerkelijk uitgevoerde controles. De toegang tot GitHub moet afzonderlijk in het Claude-account zijn gekoppeld; dit bestand verleent geen machtigingen.
